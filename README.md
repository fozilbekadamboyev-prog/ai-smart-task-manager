# AI-Powered Smart Task Manager 🧠📋

An Open-Source smart task management application that uses rule-based NLP (Natural Language Processing) to automatically detect task priorities based on context and urgency.

## Features ✨
- **Smart Priority Detection:** Automatically categorizes tasks into High, Medium, or Low priority by analyzing the keywords (e.g., "urgent", "bugun", "later").
- **Clean UI:** Built with a modern and responsive Bootstrap interface.
- **Lightweight Backend:** Powered by Python Flask and file-based JSON storage.

## How to Run Locally 🚀

1. Clone the repository:
   ```bash
   git clone https://github.com
   cd ai-smart-task-manager
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python app.py
   ```
4. Open your browser and navigate to `http://127.0.0.1:5000`
